# sneakers-identity 🐹

> 🧭 Sneakers identity service: users, groups and SSO (with its gRPC API)

## 📦 Install

```bash
go get github.com/Sneakers-PAM/sneakers-identity
```

## 🛠 Develop

```bash
task build    # go build ./...
task test     # go test ./...
task lint     # gofmt check + golangci-lint + yamllint
task license  # check Apache-2.0 headers (golic)
```
